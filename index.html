🔐 AES 加密解密工具

基于浏览器 Web Crypto API · AES-256-GCM · 数据仅在本机处理

安全说明：本工具使用 AES-256-GCM 和 PBKDF2-SHA-256。请使用强密码并妥善保存密码；忘记密码将无法解密。此工具保护文本数据，不是 ESP32 固件签名或防破解方案。
加密算法： GCM 的密钥、盐和 IV 由程序安全生成并随密文保存。
